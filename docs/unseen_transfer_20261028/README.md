# 처음 보는 교차로 시험 — 이력 감사와 시험 기준 확정

기준일: 2026-10-28. 사용자 요청의 **1번 기존 이력 정리, 2번 시험 기준 확정 완료**.
새 도로망 제작·교통 운행·학습·웹 변경은 이번 범위에 포함하지 않았다.
전체 순서는 [업데이트 계획](../unseen_intersection_update_plan_20261028.md)을 따른다.

## 확정한 결정

**쇼케이스에서 사용한 seed43 / SmartSignal V2 / `load_gate_pressure_wait35`를 그대로 사용한다.**
모델·보정 규칙·입력 특징·정규화·공통 신호 시간·기준선 구현을 교차로마다 변경하지 않는다.
새 교차로의 실제 차로 연결·길이·보호 신호와 가상 수요만 설정으로 제공한다.
시험의 주장은 지원 규격 안에서의 재학습 없는 재사용이다.

- [history.json](history.json): 학습·기존 입력·쇼케이스 이력과 원본 확인 결과.
- [protocol.json](protocol.json): 새 시험 대상의 설계, 비교 방식·지표·판정·실행 한도.
- [freeze.json](freeze.json): 위 두 파일과 감사 도구, 기준 파일 17개의 SHA256 동결 기록.

동결 기록 SHA256: `d23c13349a5c2afd5f471028472af976ae6e2c4f9de63294952a064bcc79a5d6`.
이후 규칙을 바꾸려면 기존 기록을 덮어쓰지 않고 별도 버전과 새 최종 시험을 만든다.

### 원본 확인의 한계

최종 release에 참조된 자료 중 5개가 현재 컴퓨터에 없다:

- 과거 validation/final의 독립 감사 JSON 2개.
- 과거 validation/final의 실행 manifest 2개.
- 과거 `selection.json` 1개.

있는 자료는 해시가 일치했고, 없는 자료는 `missing`으로 명시했다.
과거 성능 수치는 이전 보고·동결 요약의 기록으로 보존하며 이번 감사에서 전체 원시 결과를 재검증했다고 주장하지 않는다.
이 상태에서도 현재 모델·규칙을 동결하고 **앞으로 새로 생성·저장할 시험의 독립성**을 검증할 수 있다.

새 입력의 제외 목록에는 도로망 SHA 32개, 수요 SHA 243개, 과거 수요 seed 240개와 기하 요약 식별값 31개를 저장했다.
실패·기존 평가·기존 준비 파일도 보수적으로 포함했다.
파일 이름·ID·좌표 이동만 바꾸는 방식은 신규성으로 인정하지 않는다. 기하 요약은 중복을 걸러내는 보조 수단이며, 그 값이 다르다는 사실만으로 새 교차로나 안전성을 인정하지 않는다.

## 3. 쇼케이스와 차이가 있는 시험 대상

기존 쇼케이스는 신호 교차로 3개가 연결돼 있고, 각 교차로는 4개 접근 방향·4개 녹색 후보를 가진다.
접근로는 이미 1·2차로가 혼합돼 있다. 접근 차로 길이는 352.43~642.98m이며, 신호 교차로 사이 차로는 약 535~544m다.

| 대상 | 동결한 설계 입력 | 쇼케이스와 실질적인 차이 |
|---|---|---|
| A `zt_t1_short` | 독립 삼거리 1개, N/E/S 각 1차로. 중심~끝점 거리 150/330/210m | 삼거리·단일 교차로 구조 + 짧은 차량 저장 공간 |
| B `zt_x31_asymmetric` | 독립 사거리 1개. N/S 3차로, E/W 1차로. 끝점 거리 N320/E140/S260/W180m | 쇼케이스에 없는 3차로 주도로와 3:1 용량 비대칭 + 짧은 저장 공간 |
| C `zt_pair_short` | 사거리 2개, 중심 간격 160m, 연결 도로 2차로. 양 끝 주도로 3차로·동서 지선 1차로 | 2교차로 연결 구조 + 짧은 연결 도로의 정체 역류 조건 + 3차로 주도로 |

각 대상은 **구조·차로 용량·저장 공간 중 최소 2종류의 실질적인 차이**가 있어야 한다.
각도·이름·수요만 바꿔서 이 조건을 채울 수 없다.
T/X와 1~3차로는 학습한 유형이므로, 학습하지 않은 교차로 유형 자체에 대한 성공으로 표현하지 않는다.

위 거리는 제작에 쓸 설계 입력이다. 생성 후 실제 SUMO 차로 길이로 차이를 다시 검사한다.
A/B는 180m 이하 접근 차로, C는 100~180m 연결 차로를 요구한다.
모든 대상은 과거 도로망·기하 요약과 중복되지 않고, 보호 신호 충돌·공유 차로·미서비스 차로 검사를 통과해야 한다.
기존 빌더의 일부는 균일 차로·3교차로 구조를 전제하므로, **새 환경 제작 도구만 별도로 보완**한다. 동결한 모델·규칙·관측 코드는 수정하지 않는다.
아직 실제 도로망을 생성하거나 이 구조의 호환성을 검증하지 않았다.

## 4. 동결한 비교·수요·평가 기준

- 기존 7개 관측 특징, 5초 판단, 녹색 15~60초, 황색 3초, 전체 적색 2초, 최대 적색 우선 규칙 180초를 유지한다.
- 수요는 한산·혼잡·방향 편중 × 새 표본 3개, 총 27조건이다. 새 seed 27개를 예약했고 과거 seed와 중복되지 않음을 확인했다.
- 기존 수요 생성기의 Poisson 유입과 차로당 기본 180/360/240대/시를 유지한다. 방향 편중은 300초에 주방향을 바꾼다.
- 승용/버스/트럭의 생성 가중치는 80/10/10이다. 실제 생성 대수는 별도 기록한다.
- 각 제어에 동일한 명시적 출발 일정·차량·경로·seed·900초(유입 600 + 정리 300)·안전 제약을 적용한다.
- 기본 비교: Fixed·Webster·Max-Pressure·그대로의 Smart V2, 총 108회.
- 추가 진단: 같은 안전 제약의 학습 모델 단독, V2에서 학습 점수만 압력 점수로 대체한 규칙 중심 제어, 총 54회. 주 시험의 Smart V2는 변경하지 않는다.
- 예비 확인은 기존 검증 환경에서 최대 12회. 새 시험 조건을 이용해 후보를 고르지 않는다.
- 전체 한도는 학습 0회, 교통 운행 최대 174회다. 호출별 45분 경계에서 완료 실행을 보존하고 같은 조건으로 재개한다.

### 주 성능 판정

27조건의 평균 대기행렬을 조건별 동일 비중으로 집계한다. 도착 수는 같은 예정 차량 목록에 대해 합산한다.
교차로별·수요별 평균, 개별 27조건과 수요 표본별 변동도 함께 공개한다.

| 판정 항목 | 확정 기준 |
|---|---|
| 전체 평균 대기행렬 | Fixed와 Webster 각각 대비 5% 이상 감소, Max-Pressure 대비 비악화 |
| 전체 도착 수 | 세 기준선 각각 이상 |
| 교차로별·수요별 평균 대기행렬 | Fixed 대비 10% 초과 악화 없음 |
| 운행·기록 | 실행 오류·충돌·teleport·기록 불일치 시 중단하고 원인 확인 |
| 경고 | 급제동 등을 원문 보존·별도 검토. 충돌 0을 경고 0으로 바꾸어 기록하지 않음 |

변화율은 `(Smart - 기준선) / 기준선`이다. 둘 다 0이면 변화 0, 기준선 0·Smart 양수이면 악화로 판정한다.
평균 대기행렬(대)과 대기시간(초)을 구분하고, 완료 차량의 대기·95백분위 값은 미완료·미진입 차량과 함께 해석한다.
수요 표본 3개를 학습 초기값 3개의 반복으로 세지 않으며, 모든 교차로·현장 성능이나 통계적 확실성을 주장하지 않는다.

### 학습 기여의 별도 판정

V2와 규칙 중심 제어를 같은 조건으로 비교해 평균 대기행렬 2% 이상 감소·전체 도착 수 비감소면 사전 학습 기여 목표를 통과한 것으로 기록한다.
미달이면 학습 부분의 추가 이점을 이번 세트에서 입증하지 못한 것으로 남긴다.
이 판정은 동결 V2 전체의 새 교차로 성능 판정과 분리한다. 학습 모델 단독 비교는 보정의 효과를 설명하는 진단 자료다.

최종 결과를 본 뒤 모델·규칙·기준을 바꾸거나 결과가 좋은 교차로만 골라 공개하지 않는다.
보완이 필요하면 기존 시험 결과를 개발 자료로 옮기고 별도의 새 최종 시험을 마련한다.
