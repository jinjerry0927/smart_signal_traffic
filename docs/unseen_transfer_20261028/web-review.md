# 웹 시험 모드 별도 검토

2026-10-29, 검토자Codex. 구현과 분리한 소스/데이터 흐름 점검 및 실제 운행/브라우저 검토 기록이다.

## 판단

PC 웹 시험 모드의 기능 완료를 확인했다. 공식 비교의 성능 목표 통과나 새 도로망의 물리 Pi 검증을 뜻하지 않는다.

## 소스와 데이터 검토

1. 기존 웹에 직접 새 수치를 덮어쓰지 않고 `--unseen`과 별도 페이지/어댑터를 추가했다. 기존 사용자 화면·검사 파일은 바이트 그대로 보존했다.
2. 공통 런타임은 시나리오/교차로 이름의 인스턴스화와spec 기반 지도 ID만 일반화했다. 동결 모델/정책·제어·관측·신호 시계의 생산 소스17개/평가 소스4개는 유지한다.
3. 새 어댑터는 동결 입력 사전 검사와 결과 인증 SHA, 모델 식별값을 확인한다. 실제 실행 직전에도 고정 입력/생산 식별값과 경로/수요 SHA를 검사한다.
4. 도로망 선택은 동일 잠금 아래에서 map/suite/scenarios/state를 함께 바꾸고, 작업 스레드가 살아 있으면 거부한다. 수요의 선택 도로망 소속과PC 추론 모드도 서버에서 검사한다.
5. 기존 모델 로더·신호 환경·기준선과 실패 중단 동작을 재사용한다. 새 비교 입력이나 원래162개 운행의 출력에 쓰지 않는다.
6. 화면은 실시간/저장 비교, 전체27짝/공통22조건/선택망 조건 수를 구분한다. Webster 실패5회와 학습 기여 미달, Max-Pressure 대비 악화를 표시하며 성공 조건만으로 전체 통과를 주장하지 않는다.
7. 새로고침 시 실제 실행 값 표시와 다른 탭의 도로망 변경 동기화를 점검했다. 다음 실행 준비값은 완료 후 사용자가 바꿀 수 있도록 유지한다.

## 검증 증거

신규5검사·기존19검사 PASS. 새3망900초 실제 웹 운행은 동결 기준의 모든 기본 지표/720신호·행동/636통행 기록과 일치했다. 기존 경주60초 회귀와 브라우저의 일시정지/계속/정지도 확인했다.
18초 일시정지 중 시간 불변, 혼용/중복 거부400/409,22초 정지 prefix 재생 일치이며, 실제 웹5회에서 충돌/teleport/경고0이다.
브라우저622px의 넘침/오류/경고0과 동적 카드/수요 수를 확인했다. Node 구문 검사·Python AST를 확인했다.

원시 명령·경로·한도는 [웹 실행 기록](web-trial.md), 공식 비교 결론은 [실험 결과](results.md)를 따른다.
남은 연구 문제는 성능/학습 기여 미달과 실패의 미세한 양보/선행차 원인이다. 새 정책 보완이나 물리 Pi/발표 리허설은 완료로 기록하지 않는다.
