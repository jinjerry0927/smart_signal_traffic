## 완료한 기능

- `demo_web_pi.py --unseen`으로 새 시험 화면을 연다. 기존 기본 실행의 경주/Pi 화면은 유지했다.
- 경주 쇼케이스·새 삼거리·3:1 사거리·짧은 연결2교차로를 선택하면 지도·신호 ID/수·수요 목록·저장 결과가 함께 바뀐다.
- 같은 seed43/V2/wait35 모델을 PC에서 추론한다. 각 새 도로망에 한산/혼잡/방향 편중×표본3, 총9개 수요를 제공한다.
- 실시간 시연과900초 저장 비교를 구분한다. 전체27짝의Fixed/Max-Pressure 수치, 공통 완료22조건, 선택 도로망의 공통 조건 수,Webster 실패5회와 학습 기여 목표 미달을 표시한다.
- 실행/일시정지 중 도로망·수요 혼용과 중복 실행을 서버에서 거부한다. 일시정지·계속·정지·배속을 연결했고, 새로고침/다른 탭에서도 실제 수요·시간·배속에 맞춰 표시한다.
- 기존 사용자 `dashboard.html`과 `tests/test_signal_demo.py`를 바꾸지 않았다. 시작 시점의 웹/런타임/CLI/검사5파일을 `.codex-artifacts/unseen-web-before-20261029/`에 보존했다.

## 실제 검증

- 새 웹 검사5개 PASS, 기존 웹·원격 추론/배포 검사19개 PASS. 기존 물리 Pi를 시험한 결과는 아니다.
- 새3망의 `quiet_s00`/Smart 각900초를 HTTP 시작으로 실제 운행했다. 평균/최대 대기행렬·유입/도착/잔류 등 모든 기본 지표,720개 신호 경계와 제어 행동,636개 차량별 통행 기록이 원래 동결 비교와 일치했다.
- 기존 경주60초 실행 회귀도 완료했다. 이 짧은 검사는 시작/관측/신호 연결 확인이며 전체 통행 성능 재평가로 세지 않는다.
- 실제 브라우저에서 연결 구간60초 예정 운행을18초에 일시정지했다. 시간이 멈추는 것을 확인했고 도로망 변경409·다른 도로망 수요400·중복 실행409를 확인했다. 계속 실행 뒤22초에 사용자 정지됐고, 대기행렬·도착·신호 경계가 원래 원시 기록의 같은 prefix와 일치했다.
- 웹 통합 운행은 총5회(완료4/사용자 정지1)이며 충돌·teleport·경고0이다. 원래 기능/예비/비교177시도와 분리하므로 이번 전체 물리 운행은182시도다. 웹 재현을 새로운 독립 시험 표본으로 더하지 않는다.
- 브라우저622px에서 가로 넘침0, 오류/경고 로그0, 연결 구간 신호 카드2개·수요9개를 확인했다. JavaScript 구문 검사와 변경 Python AST 검사 PASS.
- 실제 UI 확인 중 새로고침 시 선택 상자가 실행 설정을 반영하지 않던 표시 문제를 고쳤고, 수정한 화면에서60초/1배/일시정지18초가 유지되는 것을 다시 확인했다. 정책·물리 운행 결과는 변경하지 않았다.

기계 판독 기록: `results/runs/unseen_web_checks_20261029/checks.json`, `interaction.json`.

## 시작 방법

NumPy와SUMO가 준비된 프로젝트 환경에서는 다음 명령을 쓴다.

```powershell
python demo_web_pi.py --unseen --port 8001
```

이 컴퓨터에서 실제 사용한 실행기는 다음과 같다.

```powershell
& 'C:/Users/jinuk/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -X utf8 -B demo_web_pi.py --unseen --port 8001
```

[웹 시험 화면](http://127.0.0.1:8001/)에서 도로망·수요·신호 체계·시간·배속을 선택해 시작한다. 현재 서버는 이 주소에서 실행 중이며 SUMO는 정지한 준비 상태다.
결과는 별도 `results/runs/unseen_web_20261029/`에 저장한다. 같은 경로의 결과를 덮어쓰지 않는다.

```text
tests/test_unseen_web.py
tests/test_signal_demo.py
node --check .codex-artifacts/unseen-web-script-20261029.js
tools/check_unseen_web_live.py
```

마지막 명령은4개의 실제 운행을 시작하는 재현 검사다. 기존 검사 결과가 있으면 덮어쓰기를 거부한다. 이미 완료한 검사를 확인하려면 기존 JSON·manifest·원시 기록과SHA를 읽고, 새 운행을 불필요하게 반복하지 않는다.

## 남은 범위

이번 웹 모드는PC 추론으로 검증했다. 새 도로망의 물리 Pi 추론·발표 리허설/PPT는 별도 후속 작업이다.
Max-Pressure 대비 대기행렬과 학습 기여 목표 미달은 남아 있다. 정책을 보완하려면 별도 개발/검증 환경과 새로운 최종 시험이 필요하며 이번 시험 결과로 재선정하지 않는다.
