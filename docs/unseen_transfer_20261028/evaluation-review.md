## 발견한 문제와 처리

1. 초기 소스 검토에서 ‘재개 전 완료 원시 파일 확인’과 ‘예정 교차로·제어 조합 대조’를 강화했다. 도로망/추론 생산 소스는 변경하지 않고 기존 기능 검사 원시 기록을 다시 확인했다.
2. 예비8번째 `valid_x3_quiet/webster`의 독립 검증이450초에서 불일치해 후속 실행을 중단했다.390초의 주기 계산에서 Python 실수 목록 합산과 NumPy float64 배열 합산의 차이가5초 올림 경계에 걸려 생산 녹색25초를 검증기가20초로 계산한 문제였다.
3. 생산 baseline·모델·입력·신호 규칙은 유지하고, 독립 검증기의 float64 산술과 정확히 직렬화된 정책 입력 재생을 수정했다. 원시 관측 재계산 허용 오차 확인은 유지했다.
4. v1의4개 평가 소스·동결 파일·실패 batch·7개 기존 검증 기록·8개 완료 운행 원본을 보존했다. 수정 회귀 검사 통과 후 v2 검증서로8개 원시 운행을 재감사했다. 차량 재운행은0회다.
5. 재감사 이식은 최종 비교 전의 validation pilot에만, 도로망 제작·추론 생산·모델·규칙·입력·실행 환경이 모두 같은 경우에 허용했다. 본 비교에는 이러한 이식을 허용하지 않는다. 나머지4예비 운행을 이어12회 전체를 검증했다.
