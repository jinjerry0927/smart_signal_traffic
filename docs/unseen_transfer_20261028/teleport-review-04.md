# 중단·미실행 접미 배치 검토 04

검토자 Codex. 별도 검토 후 연속 비교라는 기존 사용자 권한 안에서 미시도16개만 수집한다.
원래 모델·규칙·입력·관측·제약·900초·기준과 최대162비교/177교통시도를 유지한다. 실패를 재실행하거나 기존 중단 배치를 성공으로 바꾸지 않는다.

## 네 번째 실패의 사실과 한계

후속03은5개 완료 뒤 `zt_pair_short_directional_s00/webster`에서 전체 중단됐다. 현재142완료/4실패/16미시도다.
승용차 `veh_00146`은 `zt_b_E_in → zt_link_in → zt_a_W_out` 경로로, 연결 차로1에서 다음 우회전 차로0으로 변경해야 한다.
181~480초의300개 연속 관측에서0.1m/s 미만, 마지막 사전 관측의 대기300초를 확인했다.480초 `yield` teleport는481초 관측에 기록됐다.
482프레임/194결정을 독립 재생해 신호·관측·정책 일치를 확인했다. 충돌0/teleport1이고, [진단·원시 SHA](teleport-diagnosis-04.json)를 보존한다.

이번 상류 녹색280~305/390~405초와 하류 녹색290~305/415~440초에는 일부 겹침이 있다. 수신 차로1의 차량 수도9~15대로 변한다.
따라서 이전 표본의 ‘녹색 시점이 겹치지 않음’만으로 이 실패까지 설명하지 않는다. 연결로 차로 변경, 교차로 내부 정체·양보 간격 등의 직접 원인은 위치/선행차 자료가 없어 미확정이다.
정적 차종·경로 검사와 기능 검사의 통과, 다른 제어의 동일 입력 완료는 보존하되 고부하 통행을 무조건 보장했다는 의미로 확장하지 않는다.

## 별도 검토와 다음 실행

실행/관측 재생 오류가 아닌 실제 장시간 대기 teleport임을 확인했다. 이를 제어/입력의 한계 사례로 남기고 나머지 원래 예정 비교를 수집한다.
기존 동결 소스4개/기준17개·후속 실행 소스와 이전 검토/실패 원시 해시가 일치한다. 모델·규칙·도로망을 이 결과로 조정하지 않는다.
실패 부분 지표는900초 완료 평균에서 제외하고 모든 실패와 비교별 완료 짝 수를 함께 공개한다. 원래 전체 사전 목표 통과는 판정하지 않는다.
오류·충돌·teleport·식별/원시 불일치 시 전체 중단과 새 검토를 유지한다. 자동 실패 재개나 재시도는 없다.
