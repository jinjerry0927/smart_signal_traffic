후속02는5개 완료 뒤 `zt_pair_short_busy_s02/webster`의 `yield` teleport로 전체 중단됐다. 전체137완료/3실패/22미시도다.
버스 `veh_00172`의 경로는 `zt_b_N_in → zt_link_in → zt_a_S_out`으로 연결 차로0에서 다음 직진으로 이어져 필수 차로 변경이 없다.

상류 북쪽 녹색360~390초의 모든 관측에서 연결 차로0에15대가 있었고, 하류 북쪽 녹색295~310/410~425초와 겹치지 않았다.

## 검토와 후속 범위

세 혼잡 표본의 Webster가 모두 장시간 대기 teleport로 실패했다는 결과를 유지한다. 다른 제어의 미시도 결과를 수집해 조건별 적용 가능성과 처리량/대기행렬의 차이를 확인한다.
후속 실행 소스와 이전 검토 원문/원시 SHA, 기존 동결 소스4개/기준17개가 일치한다. 추가 소스·생산 코드·모델/입력 변경이 없다.
새 진단 전용 도구의 첫 읽기에서는 로그 숫자 뒤의 마침표까지 시간 값으로 읽어 실패했고, 정규식만 수정한 뒤 같은 원시 파일을 읽어 위 진단을 완료했다. 교통 재운행·원시 수정0회다.
해당 진단은 새 성능 지표를 만들지 않고, 실패를900초 완료 지표로 취급하지 않는다.
