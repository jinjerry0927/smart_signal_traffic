# 공통 SmartSignal 재검증·최종 확정10차

## 실행 전 계획

- 사용자 요청: 새 검증 표본에서 보완 후보를 재검증하고 이번 연구 단계의 최종 모델을 확정한다. high 난도, 코드 수정은 새 전용 도구에 한정한다. 기존 정책/모델/기본 CLI/결과를 보존한다.
- 가중치 seed43, 현재 V2, 9차 `load_aware30` 설정을 동결한다. 후보 하나만 비교하며 추가 학습과 임계값 변경은 하지 않는다.
- 새 검증: 기존 개발 기하 T1/T2/X2/X3×한산/혼잡/방향 반전×4새 표본=48조건, 103000계열 seed, Fixed/V2/load_aware30 총144회. 같은 차량 목록으로 순차 운행→원시 확인→다음 운행한다. 특히 X3 혼잡 결과와 처리량을 기록한다.
- 후보 채택 기준은 이전과 동일: V2 대비 평균 대기열2% 이상/Fixed 대비5% 이상 감소, 도착 수 양쪽 이상, 기하별/수요별 평균의 V2 대비 악화10% 이내. 미달하면 검증으로 확정한 기존43/V2를 이번 단계의 최종 기준으로 유지한다. 결과를 보고 기준을 낮추지 않는다.
- 검증 결과만으로 선택을 기록하고 동결한다. 독립 원시 감사 PASS 후 미사용 최종24조건(새 T/X×1~3차로18조건+경주 연결3교차로 새 수요6조건)을 운행한다. 최종 결과로 재선정/튜닝하지 않는다.
- 최종 비교: 선택이 V2면 Fixed/Webster/Max-Pressure/V2 96회, 후보면 기존V2를 포함한5제어120회. 따라서 실제 최대264회. 최종 입력은8차부터 보존한 원본을 사용하고 수요 SHA/seed/학습 기하 분리를 확인한다.
- 최종 기준선 성능 목표: Fixed/Webster 대비 평균 대기열5% 이상 감소, MP 대비 비악화, 기준선들 대비 도착 수 비감소, 기하별/수요별 Fixed 대비 평균 악화10% 이내. 후보가 선택됐다면 기존V2 대비 원래2% 개선 기준도 별도 판정한다. 최종 미달도 그대로 기록하고 재선정하지 않는다.
- 900초(유입600+배출300), 각 실행 명령45분 경계, 출력 분리. 오류/충돌/teleport/기록 불일치는 중단·원인 확인, 무작정 재시도하지 않는다. 정상 시간 경계만 동일 SHA 검증 후 이어서 실행한다. 급제동 경고는 원문 보존/검토한다.
- 가상 수요 연구 기준의 최종 정책이며 현장/모든 교차로 최적성의 보장은 아니다. 발표용 비교표는 사용자 요청 전 생성하지 않는다. 결과 감사가 끝난 뒤 모델/정책/근거 SHA를 포함한 최종 확정 기록과 STATE/GOAL을 갱신한다.

## 검증 결과와 최종 비교 동결

새48조건144회를 완료했다. Fixed 평균 대기열25.9755대/도착15,916, 기존V2 21.0177대/도착16,012, 후보30초21.0652대/도착15,990이다. 전체 예정16,183대, 잔류는 각각267/171/193대다. 후보는 V2 대비 대기열+0.2262%·도착22대 감소로 원래2% 개선/도착 비감소 기준에 미달했다. 기하·수요별 최대 평균 악화9.5717%는10% 이내지만 나머지 기준 미달을 상쇄하지 않는다. 이전9차의−1.836% 개선은 새 표본에서 재현되지 않았다.

따라서 검증만으로 기존43/V2를 최종 비교 대상으로 선택·동결했다. 추가 학습0·후보 튜닝0, 후보 기각 근거도 보존한다. 검증 manifest/selection/SHA를 확인한 뒤 최종24조건×4제어96회를 진행하며 이 결과로 재선정하지 않는다.

도구 verify와 별도 stdlib 감사 PASS:144회·129,744초 프레임·25,920결정, 원시7특성/유입/압력/보완 행동/초별 신호/차량/지표/입력·소스·기존10,521결과 SHA 대조. 관련 검사45개와72입력0초 로드 PASS. Python3.11.0/SUMO1.26.0, 실행 오류/충돌/teleport0이다.

급제동 경고1건은 기존V2의 `confirm_ruleval_x3_quiet_s02`에만 발생했다. 트럭 `veh_00323`이534초 내부 차로 `:center_14_0`에서 경고를 냈고567초 정상 도착했으며 이 표본385대 전원 도착했다. 원문/원시/별도 경고 검토 JSON을 보존하며 집계 기록만으로 직접 원인을 확정하지 않는다. 경고를 충돌0과 혼동하거나 경고0으로 기록하지 않는다.
