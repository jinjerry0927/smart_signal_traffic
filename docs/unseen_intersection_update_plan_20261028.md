# 처음 보는 교차로 시험 — 업데이트 작업 계획

작성일: 2026-10-28. 최신 확인2026-10-29: **새 환경3개·호환·평가 준비/검토·162비교 시도 정리·PC 웹 시험 모드 완료**. 비교는157완료/5Webster teleport실패이며 성능/학습 기여 목표는 미달이다.
현재 결론은 [최종 비교 결과](unseen_transfer_20261028/results.md), [웹 시험 모드·실제 검증](unseen_transfer_20261028/web-trial.md)를 따른다.
후속 사용자의 제작·평가·연속 비교 요청에 따른 실제 상태는 [실행 기록](unseen_transfer_20261028/execution.md)과 [중단 검토](unseen_transfer_20261028/teleport-review-01.md)를 따른다.
사용자 요청 1·2번의 결과와 확정 명세는 [이력 감사·시험 기준](unseen_transfer_20261028/README.md)에 기록했다.
현재 범위와 상태는 [프로젝트 차터](project_charter.md), [STATE](../STATE.md)를 따른다.
실행은 [LOOP](../LOOP.md)의 작은 목표·검증 절차로 진행한다.
아래 초안의 미착수/예정 표현은 최초1·2번 작업 당시 범위이며 최신 상태는 위 실행 기록을 우선한다. 추가 학습·예약 실행은 하지 않았다.

## 1. 이번에 답할 질문

**학습·모델 선택·규칙 보정에 사용하지 않은 새 교차로에서도, 하나의 동결 모델·정책을 추가 학습 없이 적용할 수 있는가?**

- 적용 가능성: 지원 범위의 새 도로망을 읽고, 올바른 관측과 합법 신호로 운행하는가?
- 성능: 동일 조건의 Fixed·Webster·Max-Pressure와 비교하면 어떤 결과가 나오는가?
- 학습의 기여: 학습 점수를 사용한 부분이 규칙 중심 제어에 비해 도움이 되는가?
- 첫 시험의 결론은 동결 모델 하나의 재사용성이다. 학습 방법 전반의 우수성은 추가 실험으로 다룬다.

교차로의 차로 연결·길이·허용 신호는 설정으로 제공한다. 모델 가중치·관측 계산·정규화·보정 임계값은 시험 대상에 맞춰 변경하지 않는다.
신호 경과 시간과 관측 이력을 갱신하는 정상적인 추론 동작은 유지한다.

## 2. 재사용할 기반과 새로 필요한 것

| 구분 | 현재 근거 또는 필요한 작업 |
|---|---|
| 공통 모델·관측·신호 규격 | [범용 신호 안내](transferable_signal.md)의 기존 패키지를 재사용한다. |
| 기존 전이 실험 | [구조 변경 6차](structure_wave6_20261007.md)를 기존 근거로 보존한다. 이번 새 시험 결과로 세지 않는다. |
| 기준 모델 | [최종 확정 10차](final_signal_wave10_20261007.md)의 seed43/V2와 release를 보존한다. |
| 새로 필요 | 학습·보정 이력 대조, 미사용 도로망, 추론 전용 시험 기록, 학습 기여 비교, 교차로 선택 웹 화면. |

기존 6차는 지원된 T/X·1~3차로 유형의 새 기하 평가다. 학습에 없던 교차로 유형 전체를 검증한 것으로 설명하지 않는다.
이 문서의 기존 완료 내용은 저장소 기록을 확인한 것이며 이번 작업에서 운행 검사를 재실행한 결과가 아니다.

## 3. 첫 버전의 범위

- 지원 후보: 기존 규격으로 표현·검사 가능한 삼거리·사거리, 차량용 보호 신호, 1~3차로 범위.
- 새 도로망 3개를 사용한다. 비대칭 길이, 접근 방향별 차로 구성, 회전·연결 구성을 고려하되 실제 지원 여부를 먼저 확인한다.
- 수요는 한산·혼잡·방향 편중 3종, 각 3개의 독립 출발 일정으로 시작한다.
- 수요는 가상임을 명시한다. 실제 도로 형태를 사용해도 현장 성능으로 주장하지 않는다.
- 보행자·비보호 회전·회전교차로·오거리는 후속 범위다. 미지원 입력은 명시적으로 거부한다.
- 첫 버전은 PC에서 평가·시연한다. Pi 시연을 포함할 경우 새 입력에 대한 실제 장치 일치 검사를 별도 완료한다.

## 4. 순서와 완료 기준

ZT-0과 ZT-1의 기준 동결 부분을 완료했다. 새 입력에 대한 호환 검사는 환경 제작과 함께 수행한다.
나머지 단계는 예정 작업이며 각 단계의 완료 증거를 확인한 뒤 다음 단계로 진행한다.

| 단계 | 해야 할 일 | 완료 기준 |
|---|---|---|
| ZT-0 이력·설계 정리 — 완료 | 학습·검증·보정·과거 시험 이력과 지원 범위·비교·판정을 확정했다. | 기존 쇼케이스 모델·규칙 유지, 새 대상의 차이 조건과 제외 이력을 명세·감사 파일에 기록했다. |
| ZT-1 기준 동결·입력 검사 — 동결 완료 / 새 입력 검사 대기 | 모델·정책·관측·안전 규칙·제어 소스 17개와 명세 식별값을 기록하고 변경 차단을 검사했다. | 새 도로망의 차로·신호·관측 호환성은 ZT-2에서 제작 후 실제 확인한다. |
| ZT-2 시험 환경 제작 | 새 도로망 3개와 27개 수요 조건을 만들고 출발 일정·경로를 고정한다. | 학습·보정·과거 평가와의 중복 대조, 정적 검사, SUMO 로드, 차량·관측·신호 연결 확인을 통과한다. |
| ZT-3 평가 도구·학습 기여 비교 | 4개 기본 제어와 2개 진단 제어를 같은 조건에서 실행·기록하도록 구성한다. 기존 검증 환경으로 예비 확인한다. | 추론 전용 실행, 동일 입력·제약, 결과 분리, 중단·재개, 모델 보존, 원시 기록과 지표 일치를 검사한다. |
| ZT-4 새 환경 본 평가 | 동결한 조건에서 순차 운행하고 매회 기록을 확인한다. | 모든 예정 실행 또는 중단 이유가 기록되고, 교차로별·전체 결과와 악화 조건을 확인한다. |
| ZT-5 웹 시험 모드 | 경주 전용 설정과 새 도로망 설정을 공통으로 읽고, 교차로 선택·지도·모델 정보·결과를 연결한다. | 도로망을 바꿔도 신호·차량·교차로 ID가 맞고 같은 정책을 사용하며, 실행 중 설정 혼용을 차단한다. |
| ZT-6 발표 자료·리허설 | 학습/시험 지도, 교차로별 비교 그래프, 실패 조건, 재현 방법과 시연 순서를 정리한다. | 발표 수치를 원시 기록까지 확인하고 시연을 반복 재현한다. 기능 완료와 성능 입증 여부를 각각 기록한다. |

ZT-0에서 이력과 판정 기준을 정하고 기준을 동결한 뒤 최종 시험 대상을 확정한다.
ZT-2의 연결 확인은 입력·환경 오류를 찾기 위한 것이다. 최종 대상의 성능을 이용해 정책을 보완하면 그 대상을 개발 자료로 옮기고 새 최종 대상을 마련한다.
성능 실험 전에 비교 방식·기준·수요·시간·중단 조건을 최종 동결한다.

## 5. 비교 구성과 확정 실행 한도

| 제어 | 확인할 내용 |
|---|---|
| Fixed | 고정 신호 기준. |
| Webster | 기존 구현의 교통량 기반 시간 산정 기준. |
| Max-Pressure | 추가 학습 없이 교통 상태에 반응하는 기준. |
| SmartSignal V2 | 현재 동결 모델과 공통 보정 규칙의 재사용 성능. |
| 학습 모델 단독 | 같은 안전 제약에서 V2 보정의 추가 효과를 확인한다. |
| 규칙 중심 진단 | V2 보정 구조에서 학습 점수를 압력 점수로 대체해 학습 부분의 기여를 확인한다. 정확한 동작은 본 평가 전에 동결한다. |

- 예비 실행: 기존 검증 도로망 2개 × 수요 1조건 × 6제어 = 최대 12회. 실행 시간·기록 연결을 확인한다.
- 기본 본 평가: 새 도로망 3개 × 수요 3종 × 표본 3개 × 4제어 = 108회.
- 학습 기여 진단: 같은 27조건 × 추가 2제어 = 54회.
- 초기 계획은 예비 12회 + 본 평가 162회 = 최대 174회다. 새로운 모델 학습은 포함하지 않는다.
- 운행 시간은 유입 600초 + 정리 300초로 확정했다.
- 호출별 벽시간 한도는 45분이다. 예비 실행으로 전체 소요 시간을 측정하되, 시간 경계에서는 기록을 보존하고 같은 동결 조건으로만 재개한다.
- 3개의 수요 표본은 교통 변동 반복이다. 서로 다른 학습 초기값의 반복 실험으로 세지 않는다.

## 6. 평가·결론 규칙

- 주 지표: 실행 구간 전체의 평균 대기행렬, 도착·미완료·미진입 차량 수.
- 보조 지표: 완료 차량 대기·95백분위 대기, 여행시간, 정차, 판단 지연, 교차로별 최악 악화.
- 모든 방식에 동일한 명시적 차량 목록·출발 일정·경로·SUMO seed·운행 시간·안전 제약을 적용한다.
- 평균 대기행렬(대)과 차량 대기시간(초)을 구분한다. 완료 차량 지표와 남은 차량을 함께 해석한다.
- 전체 평균뿐 아니라 교차로별·수요별·개별 조건 결과와 반복 간 변동을 공개한다.
- 학습 기여 비교는 같은 조건의 짝으로 분석하고, 학습 판단·보정·대체 제어의 사용 기록도 확인한다.
- 성능 기준 확정: Fixed/Webster 대비 평균 대기행렬 5% 이상 감소, Max-Pressure 대비 비악화, 기준선 대비 도착 수 비감소, 교차로별·수요별 Fixed 대비 평균 악화 10% 이내. 결과를 본 뒤 완화하지 않는다.
- 학습 기여는 같은 V2 흐름에서 학습 점수를 압력 점수로 대체한 진단 제어와 별도 비교한다. 평균 대기행렬 2% 이상 감소·도착 비감소를 사전 목표로 고정했고 주 성능 판정과 구분한다.
- 오류·충돌·teleport·기록 불일치는 후속 실행을 중단하고 원인을 확인한다. 급제동 등 경고는 원문과 해석을 별도로 보존한다.
- 성능 미달도 유효한 결론으로 남긴다. 최종 시험 결과로 재학습·규칙 조정·모델 재선정을 하지 않는다.
- 보완이 필요하면 별도 개발·검증 환경에서 진행하고 새 최종 시험을 설계한다.

## 7. 웹·발표에서 보여줄 증거

1. 학습·보정 환경과 새 시험 환경의 차이.
2. 실행에 사용한 모델·정책 버전과 시험 전후 동일성 확인.
3. 학습을 호출하지 않는 추론 전용 실행에 근거한 추가 학습 0회 표시.
4. 교차로를 바꿔 같은 모델을 적용하는 화면.
5. 기본 4제어와 학습 기여 진단의 실제 결과, 악화 조건·한계.

공식 평가와 전시장 짧은 시연을 구분한다. 저장 결과 재생이면 재생으로 표시한다.
교차로 선택 화면은 본 평가에서 확인한 입력·모델·결과를 사용한다.
브라우저 조작과 지도·신호 ID·일시정지·정지·도중 설정 변경 차단을 실제 확인한다.

| 담당 | 맡을 일 |

## 9. 후속 확장

- 단일 교차로 학습과 다중 교차로 학습을 동일 예산으로 비교한다. 여러 학습 초기값의 반복은 이 단계에서 계획한다.
- 독립 교차로·수요 표본을 늘려 적용 범위와 불확실성을 더 확인한다.
- 지원 범위 안에서 관객이 새 환경을 조합하고 같은 모델로 시험하도록 확장한다.
- 실제 Pi의 새 입력 추론 일치·지연·통신 복구를 검증한 뒤 장치 시연을 연결한다.
