  모델 고정 후 새 미사용 최종 조건을 작은 배치별로 진행한다. 이미 완료한180회와 경주 최종 평가를 이유 없이 반복하지 않는다.

## 신호 진단과 한계

신규 `tools/run_signal_diagnostic.py`는 기존 관측·행동·보상·난수 흐름을 유지하며
상태 조회와 별도 파일만 추가한다. 매초 실제/요청 신호 상태 일치와 관측 유한성을 확인하고,
충돌·teleport·SUMO 경고가 나타나면 실행을 중단한다. 기존 학습/평가 코드는 수정하지 않았다.
각 `diagnostic_seconds.csv`는0~900초·상3개의2703행이며 AI 결정/점수 기록은180개다.

- 유입 구간0~600초에 끝난 녹색의 평균: Fixed25초(20회), AI37.5초(14회).
- 다른 합법 상에 대기가 있어도 현재 녹색을25초 이상 유지한 AI 결정34회.
  예: 90초 시점 현재 상의 정지 대기는0대, 진입 중 차량은6대이며 다른 상의 대기는6대였다.
- 마지막 녹색 이후90초 넘은 상의 대기 차량·초 합계: Fixed0, AI1250. 이는 차량별 평균 대기와 다르다.
- 완전히 빈 진입부를 녹색으로 유지하면서 다른 상이 기다리는 AI 결정은 확인되지 않았다.

긴 녹색 유지 패턴은 원인 후보이며 학습 편향 전체의 원인을 확정한 것은 아니다.
시간별 상태는 같은 시각의 행동 변경 직전 기록일 수 있으므로 황색3초/전체 적색2초를 행 개수만으로 판정하지 않는다.
녹색 기간은 전환 때의 경과 값으로 구했다. 기록 비용을 포함한 결정 지연은 일반 추론 성능 비교에서 제외한다.
