# SmartSignal 첫 경주 전이 평가

확인일: 2026-10-03. 사용자가 실행한 결과를 Codex가 읽어 검증했다.
추가 운행·학습은 실행하지 않았다. 이번 후보2개(30회/150회) 중 검증에서 선택한150회 모델을 그대로 평가했다.

평균 대기행렬은 같은900초(유입600초+정리300초)의3개 수요 시나리오 평균이다.
도착/예정·미완료는3개 시나리오 합계다. 완료 차량 평균 대기는 도착 수로 가중했다.
이 평균은 미완료 차량을 포함하지 않으므로 대기행렬·미완료와 함께 해석한다.
모든 제어기의 미진입·충돌·teleport는0이고12회 전체 경고 로그도 비어 있다.

SmartSignal의 평균 대기행렬은 Fixed보다19.05%, Webster보다7.35% 낮다.
도착 차량은 Fixed보다140대, Webster보다23대 많으며 네 방식 중 가장 많다.
Max-Pressure는 평균 대기행렬이 조금 낮고 완료 차량 평균 대기가 더 짧지만,
SmartSignal보다 미완료 차량이109대 많다. 모든 지표에서 단일 방식이 우월하지는 않다.

따라서 원활한 통행이 완전히 해결됐다고 볼 수 없다.

## 확인한 증거

- 학습에 사용되지 않은 경주 실험 도로망에서 용강·근화여고·승삼 세 교차로를 재학습 없이 제어했다.
- 모델 SHA256이 최종 평가 전에 선택·기록한150회 모델과 일치한다.
  `4d3e7fc8ca45999a71c761f19ec9a5c527fe440ccffa438c0985c3f4fef8be98`
- 경주 도로망 해시는 모델의 학습 도로망 목록에 없다.
- 각 시나리오의 네 제어기가 같은 도로망·동결 수요·seed·신호 제한을 사용했다.
- 12개 실행 manifest와 CSV의 상태가 모두 완료다.
- 원시 `tripinfo.xml`의 완료 차량 수·평균 대기가 CSV와 일치한다.
- 원본 결과는 `results/runs/transferable_gyeongju_150/`에 보존했다.
  요약·해시·검증 기록은 `.codex-artifacts/transferable-final-review-20261003.json`에 있다.

## 결론과 다음 작업

이번 시작 실험에서는 학습하지 않은 경주 실험 도로망에 재학습 없이 적용했고,
Fixed·Webster 대비 전체 평균 대기행렬과 도착 수의 개선을 확인했다.
이는 실험용 지도 한 도로망·가상 수요3종·수요별 단일 seed에 한정된 결과다.
한산한 상황에서의 약점과 미완료 차량이 남고, 실제 교통량·보행자·센서·현장 신호기는 검증하지 않았다.
모든 교차로에서 최적이거나 현장 투입 가능하다는 근거로 확장하지 않는다.

이번 최종 평가 결과와 모델을 보존하고 결과 정리/관제 연결의 기준으로 사용한다.
추가 개선은 별도 연구 배치로 정의하고 학습·검증 자료에서 설계한다.
이번 경주 최종 테스트를 반복 튜닝 기준으로 사용하지 않는다.
