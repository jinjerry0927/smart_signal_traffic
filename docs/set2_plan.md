## 선정 기준과 범위

- 금성로를 따라 남측 4지(`gj_south`), 동대사거리 4지(`gj_center`), 알천남로 접속 3지(`gj_north`). 남·북측 이름은 도로에 따른 설명이며 공식 교차로 명칭을 주장하지 않는다.
- OpenStreetMap API의 2026-09-17 원본을 사용한다. 확대 bbox: `129.199,35.849,129.213,35.861`.
- 원본 기하와 확인 가능한 차로 태그를 사용하고, 미기재 차로·속도·회전 및 신호 계획은 모델 가정으로 명시한다.
- 중심 간선과 경계 접근로를 구성한다. 제외한 골목·보행·대중교통 유입은 구현 및 문서에서 명시한다.
- 신호별 실제 연결에 맞는 녹색 그룹, 녹색30초·황색3초·전체적색2초를 사용한다. 현장 신호 시간은 아니다.
- 수요는 검증용 가상 수요이며 실제 교통량 또는 AI 성능의 근거로 쓰지 않는다.
- SET1 단일 교차로와 기존 모델·결과를 보존한다. 다중 교차로 AI, 웹 연결, Pi, 장시간 학습은 후속 세트다.

## 검증과 종료 조건

1. 저장한 원본에서 도로망과 메타데이터를 재생성할 수 있다.
2. 정확히 세 신호 교차로의 ID·좌표·신호 길이·녹색/황색/전체적색 순서가 일치한다.
3. 모든 허용 회전과 두 방향의 연속 교차로 통행을 실제 SUMO에서 검증한다.
4. 가상 수요의 출발·도착·잔류를 기록하고 충돌·teleport·경로 오류가 없어야 한다.
5. 독립 검토 및 관련 명령 통과 후 완료 기록·STATE를 갱신한다.

실험 출력은 `.codex-artifacts/set2-*`에 분리한다. 기존 실험 출력 경로 재사용은 거부한다.
도로망 빌더는 알려진 생성물인 전용 도로망·계약을 갱신한다.
실패한 결과도 보존하고 원인을 수정한다. 같은 접근의 수정이 세 번 실패하면 설계를 재검토한다.
모델 배치: 환경 구현 Sol High, 총괄/검증 설계·독립 검토 Astra Extra High.
