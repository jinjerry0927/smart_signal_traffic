## 현재 인계 범위

사용자가 시뮬레이션·학습·평가를 직접 실행하기로 범위를 조정했다. 이후 Codex 작업은
환경·실행 코드 준비와 최소 로드 확인으로 제한한다. 아래의 운행 검사 목표는 이전 실행 범위의 이력이다.

- `network/gyeongju_industrial/demo.sumocfg`: 상대경로로 도로망과 예시 차량382대를 함께 여는 설정.
- `industrial.net.xml`, `contract.json`, `source/`: 교차로3개·진출입8개·경로56개·제어 회전44개와 지도 출처.
- `tools/build_gyeongju_industrial.py`: 재현 빌더. `tools/run_gyeongju_industrial.py`: 사용자가 직접 실행할 선택 도구.
- 검사: `python -X utf8 -B tests/test_gyeongju_industrial.py` 5개, 기존 `tests/test_gyeongju_corridor.py` 5개 통과.
- 최종 설정 로드만 확인: `sumo -c network/gyeongju_industrial/demo.sumocfg --end 0 --no-step-log true` 종료0.
- 이전에 시작한 마지막 실행은 `.codex-artifacts/industrial-offset-validation-20261001/summary.json`에 PASS로 종료되어 있다. 현재 도로망 SHA가 그 실행과 일치한다. 이후 추가 운행은 시작하지 않았다.

신호는 현장 값이 아닌 보수적인 실험 설정이다. 진입 차로별 보호 신호, 근화 offset105초를
사용해 대형차 내부 양보 대기와 반복 출구 막힘을 보완했다. 동일 차로의 회전은 함께 연다.
배출이 계속되는데 검사가 일찍 끝난 기록을 근거로 선택 실행 도구의 배출 한도를3600초로
설정했다. 충돌 검사·teleport300초·전원 도착 조건은 유지한다. 변경 전 실패 원시 기록도 보존했다.
이는 AI 성능 평가나 현장 신호 최적화 결과가 아니다.

다음 방향은 교차로 설정과 공통 AI 입력·행동 규칙의 분리다. 실제 실험은 사용자 담당이며 자동 착수하지 않는다.

- 환경 담당: 별도 worktree에서 OSM 원본·차로 가정·신호3개·도로망·계약·재현 빌더.
