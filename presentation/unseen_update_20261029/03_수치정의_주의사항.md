# 발표 수치의 정의와 사용 범위

우선 데이터는 `data/metrics_for_presentation.json`이다. 표시용 숫자만 반올림하며, 감소율은 CSV의 원수치로 계산했다. 모든 표는 실행 결과의 기술적 요약이다.

## 전체 27조건: 반드시 같은 범위로 비교

| 제어 | 조건 수 | 평균 대기행렬(대) | 900초 내 도착 합계 | 미완료 합계 |
| --- | ---: | ---: | ---: | ---: |
| Fixed | 27 | 39.859 | 8,356 | 681 |
| Max-Pressure | 27 | 31.483 | 8,387 | 650 |
| SmartSignal V2 | 27 | 32.273 | 8,709 | 328 |
| 학습 모델 단독 | 27 | 33.807 | 8,660 | 377 |
| 규칙 중심 진단 | 27 | 31.452 | 8,388 | 649 |

예정 차량은 각 제어의 27조건 합계 9,037대다. 평균 대기행렬은 매초 대기 차량 수를 900초 평균한 뒤 조건들을 동등 가중해 평균한다. 도착 합계는 27개의 서로 다른 실험에서 도착한 차량을 더한 값이며, 단일 도로에서 동시에 8,709대를 처리했다는 뜻이 아니다.

## 동일 조건 완료 짝의 상대 비교

변화율 `100 × (V2 평균 / 기준선 평균 − 1)`. 음수는 대기행렬 감소, 양수는 증가다.

| 기준선 | 완료 짝 | V2 대기행렬 변화 | V2 도착 증가 |
| --- | ---: | ---: | ---: |
| Fixed | 27 | −19.03% | +353대 |
| Webster | 22 | −20.07% | +133대 |
| Max-Pressure | 27 | +2.51% | +322대 |
| 학습 모델 단독 | 27 | −4.54% | +49대 |
| 규칙 중심 진단 | 27 | +2.61% | +321대 |

Webster 행은 쉬운 조건만 ‘선택’한 것이 아니라 양쪽 모두 완료한 조건을 모두 사용한 22짝이다. 그 밖의 5실패도 반드시 별도로 공개한다. 이 행을 전체 27조건의 성능으로 해석할 수는 없다. Webster 완료 22조건의 평균은 V2 17.519대, Webster 21.919대다.

## 도로망별 평균과 히트맵

도로망별 감소율은 각 9조건의 평균 대기행렬 비율로 계산했다. 삼거리 43.85%, 비대칭 사거리 19.38%, 연결 2교차로 17.13%.

히트맵의 각 칸은 같은 도로망·수요군의 출발 일정 3개를 사용한다. `100 × (1 − 해당 3조건 V2 평균 / 해당 3조건 Fixed 평균)`이다. 개별 조건의 감소율 3개를 산술 평균한 값과는 다를 수 있다. 세 도로망의 감소율을 평균해 전체 19.03%를 계산하는 방식도 사용하지 않는다.

저장소 `cases_common_completed`의 연결망 결과는 기본 제어 4종이 모두 완료한 4조건의 요약이다. 이번 발표의 Fixed 비교 그래프는 전체 9조건 결과를 사용하므로 연결망 감소율은 **17.13%**다. **31.26%로 바꾸지 않는다.**

## 완료와 실패의 정의

- 전체 27조건 × 6제어 = 162시도. 정상 종료 157, Webster 정체/teleport 실패 5, 미시도 0.
- V2·Fixed·Max-Pressure·학습 단독·규칙 진단은 각각 27정상 종료. Webster는 22정상 종료 + 5실패.
- 정해진 900초까지 정상 진행한 것을 ‘정상 종료’라고 한다. ‘모든 차량 도착’ 또는 ‘연구 목표 전체 통과’가 아니다.
- 실패한 부분 운행의 큐·도착 수는 900초 성능 표에 넣지 않는다. 0이나 무한대라는 점수도 부여하지 않는다.
- 원래 일괄 배치는 첫 오류에서 멈췄다. 별도 검토 기록 뒤 미시도 조건을 이어 수집했다. 원래 프로토콜 전체 통과로 판정하지 않는다.

## 사용 가능한 문장

> 지원 범위 안의 새 가상 도로망 3종에서, 동결한 SmartSignal V2가 추가 학습 없이 동작했고 같은 27조건에서 Fixed 대비 평균 대기행렬을 19.03% 줄였습니다.

> 기존 모델과 규칙을 함께 고정한 시스템의 적용 효과를 확인했으며, 학습 자체의 추가 기여와 적응형 기준선 전체에 대한 우위는 아직 입증하지 못했습니다.

## 바꾸면 안 되는 문장

- ‘처음 보는 모든 교차로에서도 최고 성능’ → 지원 유형 안의 새 가상 기하 3종만 시험했다.
- ‘교차로 27개에서 검증’ → 도로망 3종, 제어 교차로 합계 4개, 조건 27개다.
- ‘재학습으로 19% 향상’ → 이번 추가 학습은 0회다.
- ‘대기시간·통행시간·탄소 19% 감소’ → 지표는 평균 대기행렬, 단위는 대다.
- ‘Webster보다 27조건 전부 우수’ → 완료 22짝의 평균 비교다.
- ‘Max-Pressure보다 우수’ → 큐 +2.51%, 도착 +322대여서 지표의 차이를 설명해야 한다.
- ‘AI 학습의 순수 효과 입증’ → 규칙 대체 진단 대비 학습 기여 목표 미달이다.
- ‘27/27 성공이므로 차량 전부 통과’ → 미완료 328대가 있다.
- ‘우리 AI에는 정체 오류가 발생할 수 없음’ → 해당 27조건에서는 충돌·teleport 0, 추가 취약성 검토는 남았다.
- ‘실제 교차로 성능/실제 도로 사진’ → 가상 수요 시험이며 지도는 실제 웹의 SUMO 가상망 렌더링이다.
- ‘통계적으로 유의한 효과’ → 이번 자료에서는 유의성 검정과 충분한 독립 표본 확보를 하지 않았다.
