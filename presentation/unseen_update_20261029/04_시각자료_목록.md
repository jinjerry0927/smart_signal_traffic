## 지도와 화면

지도는 `#map` SVG를 실제 웹에서 내보내고 2,400×1,488px PNG로 변환했다. SUMO 입력에서 렌더링한 도로망이며, 합성 현장 사진이 아니다. 신호는 실행 전 상태라 회색으로 표시된다. 실제 색상과 기하를 보존했다. 편집용 SVG에는 한글 글꼴로 Segoe UI / 맑은 고딕을 지정했다. `map_capture_metadata.json`에 도로망 ID·0초 상태를 남겼다.

지도마다 맞춤 축척을 사용한다. 길이를 그림 픽셀로 비교하지 말고 캡션의 SUMO 입력 수치를 사용한다. 연결망 160m는 신호 중심 간격이며, 129.6m는 교차로 내부 영역을 뺀 실제 연결 차로 길이다. 둘을 같은 길이로 혼동하지 않는다.

웹 사진은 구현 화면을 보여주는 용도다. 대기 화면의 0/300초나 0대 숫자를 성능 결과로 인용하지 않는다. 본 비교 성능은 각900초 CSV 기록 기준이다. 화면에는 지도와 신호 표시가 보이며, 도로망·수요 선택 등 위쪽 일부 조작 영역은 화면 밖이다.

## 차트

- 흰 배경, Fixed 회색, V2 청록. 평균 비교 막대는 0에서 시작한다.
- 본문5·6은 대기행렬 단위 ‘대’, 본문7은 상대 변화율 ‘%’다.
- 본문7의 음수는 개선, 양수는 악화다. 부록A는 ‘감소율’을 양수로 표시한다. 두 그래프의 부호 정의가 다르므로 축 제목을 보존한다.
- 제공된 SVG는 글자 편집이 가능하지만 차트 데이터 편집용 스프레드시트는 아니다. 완전한 PowerPoint 편집 차트를 원하면 CSV를 사용한다.
- 그래프에 이미 제목과 캡션이 있다. 파일을 그대로 쓰면 같은 문장을 중복하지 않도록 슬라이드 제목·본문 양을 조정한다. 수치·단위·표본 수·22짝 주석은 가리지 않는다.

## 데이터 파일

`01_overall_full27.csv`: 정상 종료27조건을 가진 5제어의 동일 범위 평균. Webster는 포함하지 않는다.

`02_by_road_full9.csv`: Fixed/V2의 도로망별9조건 전체 평균과 감소율.

`03_by_road_demand_full3.csv`: Fixed/V2의 도로망·수요별3조건 평균, 히트맵 원본.

`04_all27_fixed_smart_pairs.csv`: 개별 조건27짝과 도착·미완료 수.

`05_paired_baselines.csv`: V2와 각 기준선의 동일 조건 완료 짝 비교. 행별n을 반드시 읽는다.

`06_completion_counts.csv`: 전체6제어의 정상 종료·실패·미시도 수.

`07_experiment_matrix.csv`: 도로망·수요별 출발 일정 수.

`08_all162_attempts_source.csv`: 원본162행 비교표의 복사본. 실패 행의 부분 지표를 정상 종료 결과로 채우지 않는다. path열은 원래 저장소의 근거 경로이며 이 ZIP에 전체 차량 로그를 포함하지는 않는다.

`metrics_for_presentation.json`: 위 정의를 사용한 전체 정밀 수치와 모델·정책·원본 해시.
