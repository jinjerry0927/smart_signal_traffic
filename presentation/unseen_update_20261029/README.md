# 내일 발표 자료 패키지

교수님 대상 5분 발표, 본문8장 + 선택 부록2장. 실제 PPT는 사용자가 ChatGPT에서 제작한다. 이 패키지는 구조·문구·대본·질문 대응과 실제 이미지·그래프·편집용 데이터를 제공한다.

## 바로 사용하는 방법

1. ChatGPT 대화에 `unseen_update_20261029.zip`을 첨부한다.
2. `00_ChatGPT_제작요청.txt` 전체를 복사해 같은 대화에 붙여 넣는다.
3. 이름을 넣고 싶으면 발표자·학교·팀명을 함께 전달한다. 기본 자료에는 임의로 넣지 않았다.
4. 생성된 PPT에서 본문7의 한계, 도로망 그림의 ‘SUMO 가상 시험망’ 표기, Webster22짝 주석을 확인한다.
5. `01_슬라이드구성_발표대본.md`로 약5분 리허설을 한다. 부록은 질문이 나왔을 때 보여준다.

파일 업로드를 읽을 수 없는 환경에서는 요청문만 붙여도 전체 슬라이드 원고와 주요 수치를 전달할 수 있다. 이미지를 넣으려면 별도로 assets의 PNG를 전달해야 한다. ZIP 안에는 PPTX나 영상이 없으며 제공된 화면은 실제 정지 이미지다.

## 권장 흐름

문제의식 → 고정한 모델/규칙과 바뀐 환경 → 새3도로망 → 같은 조건의 비교 → 전체 효과 → 도로망별 효과 → 적응형 기준선·학습 기여의 한계 → 웹 시험 모드와 후속 작업.

핵심 문장: **기존 모델과 규칙을 고정해 새 도로망3종에 추가 학습 없이 적용했고, 같은27조건에서 고정 신호 대비 평균 대기행렬을19.03% 줄였다.**

## 내용물

- `00_ChatGPT_제작요청.txt`: 슬라이드별 원고·대본까지 들어 있는 복사본. 처음에는 이 파일 하나를 사용하면 된다.
- `01_슬라이드구성_발표대본.md`: 8장 본문과2장 부록, 배치·캡션·대본·시간.
- `02_교수님_질문대응.md`: 실험 설계·새 도로망·학습 기여·실패·잔류·현장 범위 질문의 답변.
- `03_수치정의_주의사항.md`: 분모·단위·짝 비교·완료 정의·주장 범위.
- `04_시각자료_목록.md`: 이미지·그래프의 슬라이드 배치와 데이터 연결.
- `assets/`: 실제 웹 지도3종, 웹 화면1장, 그래프7종, 기존 좌표도1장. 지도·차트는SVG도 제공한다.
- `data/`: 편집용CSV8개, 정밀 수치JSON.
- `evidence/`: 확정 비교 보고서·검증 해시·웹 결과·정체1차 진단과3도로망 설정의 스냅샷. 내부의 상대 경로는 원래 저장소 기준이다. 전체 대용량 원시 운행 로그는 원래 저장소에 보존한다.
- `manifest.json`: 패키지 내 파일의SHA-256과크기. PPT 제작에는 읽을 필요가 없다.
